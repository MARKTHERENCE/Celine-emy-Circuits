# Celine-emy-Circuits
Schematic files drawn for use with Céline, developed by Céline Audio (@Celine-audio).

# List of Circuits
Circuits of various guitar/bass amps and FX pedals. This list may expand over time.

 - ## Pedals & Effectors
   - Jordan Boss Tone V1/V2/V3
   - K-AD1 Azusa Driver
   - K-MD1 Mio Driver
   - K-YD1 Yui Driver
   - MSA Steel Pedal Fuzz
